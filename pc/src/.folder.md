# EasyCoding Deck 前端

- `main.jsx`、`App.jsx`：启动、应用导航、页面生命周期与错误边界。
- `shell/DeviceContext.jsx`：原生设备状态与操作意图的共享边界。
- `DeviceDashboard.jsx`、`dashboard/`：设备状态、五键配置、Agent 绑定、Wi-Fi、音量、位置和实时对话。
- `AppearanceGallery.jsx`、`lib/avatar-pipeline/`：形象选择、导入、生成、预览与设备同步。
- `ApiSettings.jsx`：运行时服务设置与凭据草稿。
- `SmartHome.jsx`：账号授权、能力驱动的设备控制、任务确认与执行回执。
- `component-center/`：声明式组件库、预览、创作与资源验证。
- `lib/`：共享状态、文本、协议投影与纯逻辑。
- `styles.css` 及各页面 CSS：共享视觉规则和组件样式。
- `*.test.js`：Node 行为与源码契约测试；浏览器夹具位于 `pc/tests/`。

## 数据与生命周期

设备连接、USB/WSS、认证、连接代次与音频 owner 由 Rust 管理，浏览器只提交本地 Tauri intent。串口日志读取原生连接已有的有界缓冲，不另开物理端口。

Agent 状态、草稿写入、确认发送和审批独立协商。未知写入结果、目标窗口变化或连接退役会停止当前操作，不自动选择会话或重放请求。

S3 形象同步使用设备协商的 RGB565 动画事务；实时对话区分正在停止、停止待确认和已结束，不把连接丢失当成已取得设备空闲回执。

内置组件成员和顺序读取 `pc/builtin-catalog.json`。组件声明与预览不授予设备执行或服务权限，资源预算和真实 capabilities 独立核验。

`lib/locale.js` 管理 `zh-CN` / `en-US` 状态与原生弹窗的 `localize()`；纯词库 `locale-catalog.js`、`locale-en.js` 和 `locale-dynamic.js` 覆盖组件小字、创建向导、设置与当前按键映射的完整说明。`lib/locale-dom.js` 隔离 DOM 更新，支持多行文本、textarea placeholder、ARIA 和 optgroup label，但不改输入值或 option value；用户名称/描述可用 `data-locale-ignore` 排除。监听按帧合并并清理任务，不重复触发自身。`lib/locale-catalog.test.js` 检查核心页面固定 JSX 文案与动态说明，`pc/tests/locale-startup.test.mjs` 在真实浏览器验证词库、英中往返及启动不阻塞；不替代安装包实机验收。

品牌与对外说明使用 EasyCoding Deck。界面文案保持直接、简洁，不改变现有操作语义或权限提示。
