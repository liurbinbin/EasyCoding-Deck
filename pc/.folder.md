# EasyCoding Deck 桌面端

## 模块

- `src/`：React/Vite 界面、设备状态镜像、形象管理、设置与前端测试。
- `src-tauri/src/`：Rust 原生设备连接、USB/WSS、音频、凭据、Tauri IPC 和后台生命周期。
- `src-tauri/bridge/`：托管的 Node Agent bridge、Session Bus、Hook 与适配器。
- `src-tauri/permissions/`、`src-tauri/capabilities/`：本地界面与原生命令的权限边界。
- `public/`：形象、音效与静态资源。
- `builtin-clawpkgs/`、`builtin-catalog.json`：内置组件及其顺序、形象元数据。
- `runtime-core/`：固定、有界的桌面预览 C 核心。
- `scripts/`：原生资源准备、安装包构建、生成与检查工具。
- `skills/petui/`：声明式组件创作、验证器与共享契约。
- `tests/`：静态契约夹具、浏览器与手动验收工具。
- `docs/`：Agent 接入、音频、运行资源与功能文档。

## 所有权与约束

Rust 持有设备身份、连接代次、USB/WSS writer、请求回执与音频生命周期。React 通过 DeviceContext 镜像状态并提交意图，不另建串口或 WebSocket owner，不持有配对 secret。

Wi-Fi 候选经过证书 pinning 和 nonce-bound HMAC 验证后才能接入。断线或 owner 切换终止旧录音、播放、审批与未提交形象事务；未知结果不自动重放。

Node bridge 的 hook HTTP、Agent Session Bus 与 DSH 服务只监听 loopback。DSH 插件源码位于 `integrations/dsh-easycoding-deck/`，Tauri 资源与原生 ACL 脚本从该目录取源，安装资源使用 `dsh-bridge/`。API Key 和用户配置由原生安全存储管理，不进入前端 bundle 或日志。

实时对话采用设备采集、Rust ASR/模型/TTS 和设备播放的原生链路。S3 为半双工，前端区分正在停止与停止待确认，连接退役不视为设备空闲证明。

组件能力来自实际设备协商；包 metadata、预览成功或版本号不能扩大设备、网络或 IPC 权限。预览固定运行时不执行包内任意代码。

入口 HTML 的标题与应用显示名统一为 EasyCoding Deck。开发、原生资源和离线验收见 `README.md`、`docs/runtime-dependencies.md`。源码测试、宿主构建、设备传输、实机性能与声学验证分别记录。
