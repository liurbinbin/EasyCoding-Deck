# EasyCoding Deck 工具脚本

- `prepare-desktop-resources.mjs`：准备目标平台可重定位 Node、审核过的 FFmpeg 及其声明/源码，检查本地 bridge 生产依赖，清理创作工具字节码。不会联网安装未知替代资源。macOS arm64 额外保留一个固定发行签名版 FFmpeg 的精确哈希并核验代码签名；来源证据和 macOS 26 最低要求见 `docs/macos-ci.md`。
- `build-windows-nsis-cross.mjs`：使用桌面构建回执和已准备资源生成 Windows NSIS 安装包。
- `sign-macos-local-app.mjs`、`bundle-macos-local-dmg.mjs`：本地应用签名、DMG 与构建身份核验。
- `build-*-runtime.mjs`：从 `pc/runtime-core/` 显式重建固定桌面预览 WASM；普通开发使用已提交产物。
- `verify-builtin-release.mjs`：按 `pc/builtin-catalog.json` 核验组件、创作工具与安装资源。
- `prepare-*-community.mjs`：生成社区 staging，保留组件已有声明；发布、安装与设备同步为独立操作。
- `test-framework-offline.mjs`：汇集前端、bridge、S3 transport 和桌面 harness 证据，不连接设备或运行 ignored 实机用例；Rust harness 涉及宿主编译。
- `test-background-controller-offline.mjs`：运行明确白名单中的合成 writer/reader 测试，不枚举串口、启动 GUI 或调用音频服务。
- `check-source-safety.mjs`：扫描受跟踪和未忽略的公开输入，检查二进制中的凭据、构建缓存与私有路径，拒绝符号链接；工作树已删除的索引条目不作为分发输入。
- `check-clawd-provenance.mjs`：分别核验上游原样文件与经审查的派生文件，变更时同步 `docs/clawd-mit-provenance.md`。
- `check-public-build-env.mjs`、`check-release-csp.mjs`：公开构建环境与 CSP 门禁。
- `check-gitleaks-policy.py`：核验精确的扫描器例外及正负用例，其他默认检测规则保持启用。

字体素材生成器通过 `PET_MANAGER_FONT_ASSET_DIR` 显式读取已审核字体与许可证目录。运行生成、构建、安装或实机脚本前核对其输入与副作用；非编译检查不能替代构建、设备性能或声学验收。
