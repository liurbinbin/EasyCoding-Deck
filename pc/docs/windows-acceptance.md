# EasyCoding Deck Windows 验收

本说明区分安装资源、桌面功能和设备实机证据。未执行的项目标记为待验收，不根据安装成功或协议回执推断全部功能通过。

## 安装资源

使用完整 Windows x64 安装包或 portable 目录，不单独复制主程序。确认应用目录包含：

- `EasyCoding Deck.exe`。
- `bridge/runtime/node.exe` 与 bridge 生产依赖。
- `tools/ffmpeg.exe`、对应构建说明、许可证与源码。
- 内置形象、音效和组件资源。
- 本机可用的 WebView2。

资源检查以当前 Tauri 配置和构建回执为准。不要从其他机器的构建缓存补入未审核文件。

## 桌面与设备

1. 使用可传输数据的 USB 线连接 T-Keyboard Voice。
2. 启动客户端，确认设备身份、固件版本和连接状态。
3. 检查五键映射、音量、Agent 状态与形象同步。
4. 只在目标对话和可操作输入框已打开时验证按键语音。
5. 确认草稿写入与发送是两步操作，不会自动选择会话或重复发送。
6. 验证实时对话开始、半双工播报、字幕和停止。
7. 按需完成 USB 配网、WSS 认证与 USB/Wi-Fi 切换。

同一设备串口只由一个 reader 持有。不要同时启动客户端与串口检查工具。

## 串口实机脚本

从仓库根目录，在明确确认端口和副作用后执行：

```powershell
.\firmware-s3\tools\s3_serial_smoke.ps1 -Port COM5
```

该脚本默认重新保存按键配置并将音量设为 75%。`-SkipConfig` 不跳过音量修改；`-PlayTone` 会播放音频，不代表声学验收通过。运行前先退出占用串口的客户端和其他工具。

## 故障与记录

- 记录客户端和固件版本、操作系统、USB/Wi-Fi、操作步骤和脱敏错误。
- 权限不足、串口占用、目标窗口不可写与认证失败分别记录，不直接归类为固件故障。
- 传输或写入结果未知时停止重复操作，先只读核对身份与状态。
- 不保存或回传密钥、配对 secret、录音和私人识别文本。
- Windows 文件符号链接测试需要相应系统权限，受限时单独记录环境阻断，不把未验证用例记为通过。

源码检查、构建、GUI、设备传输、网络、功耗和声学各自形成证据。完整流程见 [客户端开发](../README.md)、[固件说明](../../firmware-s3/README.md)与 [设备协议](../../firmware-s3/protocol.md)。
